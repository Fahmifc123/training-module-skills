# Briefs

Simpan Brief yang sudah disetujui di subfolder per workstream, misalnya `briefs/Big_Data/` atau `briefs/Onboarding_MLE/`.

- Template: `briefs/templates/` (Live Session dan Preparation).
- Glosarium per workstream: file `_GLOSARIUM_*.md` di subfolder workstream. Jika ada, wajib dibaca bersama Brief, dan bila bertentangan dengan kalimat di Brief, glosarium yang berlaku.
