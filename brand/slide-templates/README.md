# Slide Templates

- `Template_Training_Insignia.pdf`: acuan visual 15 komponen slide. Lihat file ini sebelum menyusun deck.
- `Template_Training_Insignia.pptx`: versi PowerPoint yang bisa dibuka dan diedit.

Kedua file dihasilkan oleh `generate_template_deck.js` di root project memakai `insignia_deck_lib.js`. Jika library diubah, jalankan ulang `node generate_template_deck.js` lalu export PDF-nya supaya template tetap sama dengan hasil library.
