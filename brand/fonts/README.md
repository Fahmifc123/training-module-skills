Taruh file font resmi Insignia di sini (.ttf/.otf) kalau ada, dengan nama file yang jelas (misal Inter-Regular.ttf, Inter-Bold.ttf). Skill html-to-png-render akan memuat font dari folder ini saat render HTML-to-PNG via Playwright, supaya tampilan konsisten dengan PPT. pptxgenjs sendiri tidak meng-embed font file — dia hanya mereferensikan nama font yang harus ter-install di sistem yang membuka file PPT, jadi pastikan nama font di colors.json/SKILL.md sama dengan yang dipakai peserta/reviewer.
