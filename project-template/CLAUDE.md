# Project materi training

Folder ini adalah project root. Skill training dipasang global dari repo training-module-skills (`TRAINING_KIT_HOME`).

- Untuk membuat atau merevisi materi dari Brief, selalu mulai dengan skill `insignia-training-module`. Skill itu yang memanggil skill lain (ppt-deck, docx-module, xlsx-tracker, html-to-png-render, image-gen, grill-me).
- Brief ada di `briefs/`, materi lama yang dipakai ulang di `materi_rujukan/`, semua hasil ke `output/`.
- Jangan menulis file apa pun ke folder repo skill.
